# Observações

**Versão independente para estudo, sem vínculo oficial.**

**Site publicado:** <https://tenentedoexercitodeproplayersemjogos.github.io/jic-mapaalocacao/>

Este repositório contém apenas o site estático e estas observações.

- O site é uma versão standalone, sem WordPress, Elementor ou plugins.
- Uso livre e ilimitado: sem contador de prazo, limite de acessos ou expiração.
- Foram removidos a telemetria, os bloqueios de devtools/clique direito e os rastreadores de UTM.
- Layout, textos, cálculos e o botão de copiar resultado foram preservados.
- O conteúdo é material educacional de terceiros. Marcas, textos e identidade visual pertencem aos seus respectivos donos.
